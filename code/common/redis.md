进入redis命令行模式：
```
redis-cli
```

## 查找
1. 模糊匹配键（KEYS）
KEYS 匹配模式   # 支持通配符 *（任意字符）、?（单个字符）、[]（字符范围）
2. 查看键的值（GET）
GET 键名   # 适用于字符串类型（String）
3. 查看键的类型（TYPE）
TYPE 键名   # 返回键的类型（string、hash、list 等）


## 新增
1. 新增字符串键（SET）
SET 键名 值   # 键不存在则创建，存在则覆盖
2. 新增哈希表键（HSET）
HSET 键名 字段名 值   # 字段不存在则创建，存在则覆盖
3. 新增列表键（LPUSH、RPUSH）
LPUSH 键名 值   # 左侧插入
RPUSH 键名 值   # 右侧插入
4. 新增集合键（SADD）
SADD 键名 值   # 集合中不存在则添加，存在则忽略

## 修改
1. 修改字符串键的值（SET）
SET 键名 值   # 键存在则修改，不存在则创建
2. 修改哈希表键的值（HSET）
HSET 键名 字段名 值   # 字段存在则修改，不存在则创建
3. 修改列表键的值（LSET）
MSET 键1 值1 键2 值2 ...   # 一次性设置多个键值对
4. 追加字符串
APPEND 键名 追加的内容   # 若键存在，在原字符串后追加；不存在则等同于 SET
5. 数值增减
INCR 键名          # 自增1
DECR 键名          # 自减1
INCRBY 键名 数字   # 增加指定数字（如 INCRBY count 5 表示+5）
DECRBY 键名 数字   # 减少指定数字（如 DECRBY count 3 表示-3）

## 删除
DEL 键1 键2 ...   # 可同时删除多个键，返回删除成功的数量
DEL $(KEYS "io-agent:*")   # 删除所有 "io-agent:" 开头的键

## 其他命令
1. 时间
EXPIRE 键名 秒数   # 设置键的过期时间，单位为秒
TTL 键名          # 查看键的剩余过期时间，单位为秒
PERSIST 键名     # 取消键的过期时间,设为永久
